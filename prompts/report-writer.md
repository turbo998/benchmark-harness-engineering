# Report writer — original recipe v1

Use only supplied summary JSON and evidence links. Every number must reconcile with the
shared metric calculations. Distinguish synthetic, project-measured and third-party data.
Explain macro/micro, planned/attempted denominators, missing costs, pending reviews,
matched task uncertainty and separate cohorts. Do not invent chart coordinates, rank
tiny fixture packs, call a known subtotal total cost, or claim an unexecuted live tier.
