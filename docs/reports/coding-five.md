# 五模型编码基准：历史事实整理

**来源性质：** `anonymized_reported`，中英文两个页面，未独立复现。
测试窗口为 2026-09-09 至 09-11，Copilot CLI 1.0.84-3。
完整表格见 [JSON](../../data/reported/coding-five/report.json)与
[逐任务评分 CSV](../../data/reported/coding-five/task_scores_and_difficulty.csv)。

## 方法

五个模型各完成同样的 11 个 Python 标准库任务：5 个原子、2 个中等、4 个复杂任务。
每模型每任务一次交付，共 55 次评分运行，严格串行；任务输入通过哈希保持一致。
每题 100 分由功能 70、规范 15、质量 15 构成。功能子项随难度变化：原子任务全部
来自隐藏测试，中等任务为隐藏 55 + 自测 15，复杂任务为隐藏 58 + 自测 12。

报告的隐藏套件规模为每模型 1310 个断言。质量包含确定性检查和有证据的主观判定。
除 Haiku 无法设置推理强度外，其他模型设为 medium。
历史执行模式允许广泛命令权限；分目录、禁用 MCP/自定义指令并不等于已验证安全沙箱。
本项目不会直接采用该模式来运行不受信代码。

## 解释与限制

本组数据说明高分答卷可能需要不同的请求数与 token，token 单价也不直接等于完成
任务的总花费；但每模型每任务只有一个评分样本，不足以产生可靠的总体优劣结论。
报告曾观察到同任务 wall time 为 230 与 821 秒，而推理时间接近，提示本地工具和
网络可造成很大波动。总时间不能冒充纯模型推理延迟。

主观质量、任务类型分布、一次性从零实现和测试窗口限制了外推。后续报告修订过
历史评分，因此本页数据只属于这个日期快照。原图、全文和完整任务/实现未转载。
新 harness 实验应保留单次证据、增加重复与任务簇不确定性，并分别记 wall、工具和
推理时间；见 [计量口径](../metrics.md)。
