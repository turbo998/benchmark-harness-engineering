## 解释与限制

费用地板下降与高分模型并存，说明选型应把完成任务的代价、隐藏功能失败和质量
判定分开，而不是只比较输出 token 标价。这里仍是小任务集、单次采样和部分主观
质量评分，分数接近不构成可靠胜负。

中英文表格核对不是第二次实验。跨批次 CLI 与环境差异、复用五模型基线以及后期
历史分数修订使这一页不能和十七模型页逐行当作同一次测量。
保留本期快照，避免把旧测试换名、把重复报告当更多样本，或把历史费用当最新报价。
