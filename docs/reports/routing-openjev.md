# OpenJev 补充路由对比

**来源性质：** `anonymized_reported`，中文一个页面，未独立复现。
测试日期 2026-10-12。新测 OpenJev MLX 4-bit；四个对照引擎直接复用
[前一期](routing-decision.md)，不是五引擎同日全部重跑。
数据见 [JSON](../../data/reported/routing-openjev/report.json)与
[含复用标记的比较 CSV](../../data/reported/routing-openjev/comparison.csv)。

## 方法与结果

40 个请求、同样五个候选描述、三轮，共 **120 次新增决策**。
27B 的 4-bit 版本运行在 48GB Apple M4 Pro；报告加载约 12 秒。

| 指标 | 新测 OpenJev 的报告值 |
|---|---:|
| 标签匹配数 / 120 | 111 |
| 匹配率 | 92.5% |
| 每轮 A 组 / 20 | 19 |
| 每轮 B 组 / 20 | 18 |
| 三轮选择一致的请求 / 40 | 40 |
| 决策中位数 | 2570ms |
| 决策 P95 | 3030ms |
| 每次平均输入 token | 237 |

按次计费为 0 不代表总费用为 0：硬件、能耗、维护和商业授权均未计入。
四个旧引擎来自前期 480 次决策；两篇合计是 600 次唯一测量，不是补充报告
新测 600 次，亦不能把对照重用再次当作独立证据。

## 概率、精度与许可

三道错误请求各重复三次，产生 9 次错误。0.6 阈值仅拦住其中 3 次，
另 6 次的所选概率约为 0.70/0.72。正确请求的回退覆盖率未知。
因此不能直接沿用另一引擎在本题集上观察到的阈值效果。

这是笔记本 MLX 4-bit 的运行，不是完整 BF16/FP8 或服务器结果。
来源引用的独立模型卡准确率 84.0% / 85.4% 和 H100 FP8 约 80ms 均非本次实测，
没有与本页数值混合。
