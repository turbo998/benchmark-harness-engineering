11 of 12 answers pointed the right way; 5 of 12 were confident enough (>= 0.9) to run automatically. Action bands: Auto if confidence >= 0.9, Confirm if 0.5-0.9, Human below 0.5.

UNDER THE HOOD

The model never sees your JSON

  "state": "Customer overcharged $30 for the third time ...",
  "questions": {
    "intent": {
      "type": "choice",
      "instructions": "What is this customer's main request?",

        "inquiry": "General plans or pricing inquiry"

    }

</options>

<answer>
At <answer> it generates nothing. It matches the hidden state at <answer> against the last token of each numbered option line in a single forward pass, then applies softmax.

ENGINEERING TAKEAWAYS

Where to use it, and where not to

✅ Good fit
  • Intent routing
  • Ticket triage and escalation
  • Tool-call checks before execution
  • GenBI domain routing
  • Picking which LLM tier to call
⛔ Not for
  • Long, multi-step reasoning
  • Anything that requires generated text
  • Final allow/deny on security (keep that in a deterministic policy engine)

Early research release: bundled server has no authentication and is not production-hardened.

Open source (Apache-2.0): github.com/strands-labs/strands-decider
